# Security Policy

## Reporting a vulnerability

Please do not create public issues for security vulnerabilities.

Instead, report them privately to the project maintainer or repository owner.

Include:

- a clear description of the issue
- reproduction steps if possible
- affected version
- risk assessment
- any suggested mitigation

## Response expectations

We will acknowledge reports as quickly as possible and work toward a fix with responsible disclosure.

## Supported versions

The project currently supports the versions covered by the active test matrix and latest package release.

If a vulnerability is discovered in an older version, we will evaluate whether a patch release is appropriate.
